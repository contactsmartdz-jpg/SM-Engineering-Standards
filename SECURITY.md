# Reporting Security Concerns

This repository publishes engineering guidance and reusable templates. Please report suspected vulnerabilities in any executable material, unsafe security guidance, or accidentally committed sensitive information responsibly.

- Prefer GitHub's **private vulnerability reporting** feature if it is enabled for this repository.
- If private reporting is unavailable, open an issue **only for concerns that do not reveal an exploit path, credential, or private data**. Ask maintainers to establish a secure channel for sensitive details.
- Do not publish tokens, customer records, private infrastructure details, or working exploit instructions in public issues.
- Include affected file/revision, impact, reproduction conditions that are safe to share, and suggested correction.

Maintainers should acknowledge and assess the report, restrict sensitive details, and document a fix without exposing private data. No fixed response-time commitment is made in this draft.
